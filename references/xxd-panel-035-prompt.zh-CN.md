# XXD Panel 035｜明艳像素积木收藏品生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。
- 也支持 Seedance 5.0 Pro、Nano Banana Pro（Gemini Image Pro）、Nano Banana 2（Gemini Image Flash）或其他兼容位图模型，但只有实际通道具备原图保真、整张成品画幅、目标语言文字，以及连贯壁纸所需多图参考能力时才可使用。
- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

只处理当前任务明确提供的这一张源照片。锁定主体或不可拆分关系、轮廓、比例、姿态、方向、动作、功能、开口、重叠、关系距离与综合色彩身份，至少保留三个源图专属线索。不要借用旧成品或其他输入的积木剪影、固定色组、模块布局、底座、道具、文字和环境。

## 重构一个可识别的模块化主体

先理解身份、动作、关系和有依据的寓意，再通过方块比例、模块几何、可信拼搭、清晰剪影、阶梯层级、可见厚度和有源图依据的局部夸张，把主体重构为一件乐高／Minecraft 式体素积木雕塑。不要把卡通简单像素化，也不要给照片套低多边形网格。动物、植物、建筑、车辆、器物和景观不强行拟人化。

通过剪影、姿态、方向、功能部件、开口、重叠、比例、色组或关系距离保留至少三个源图线索。一个主体或不可拆分关系是绝对焦点，只保留承托所需的极简底座、平面或接触阴影。禁止完整 Minecraft 地形、森林、城堡、游戏世界、无关道具、满地散砖、通用角色、游戏截图、HUD 或商品包装场景。

## 明艳源图色组与哑光 ABS

提取照片最有辨识度和精气神的颜色，转化为高纯度、高饱和的积木色组；可比原图更亮、更有能量，但必须保住源图综合色彩身份。用面积、明度与模块分组建立层级，背景明显更浅、更单纯。拒绝固定红黄蓝套色、荧光、霓虹、糖果渐变、莫兰迪、粉彩化、灰雾、脏色和为了显高级而刻意降饱和。

呈现可信的哑光 ABS 积木塑料：平整表面、克制柔和反光、清晰拼接缝、阶梯厚度、可信接点与叠压、自然接触阴影。使用柔和清晰光线，让颜色鲜艳通透并显出立体结构。拒绝金属、玻璃、镜面高光、过度 CG 反射、融化无缝团块、三角低模面、廉价游戏渲染和电商玩具摄影。

## 安静陈列与克制模块文字

背景保持低信息量，用大面积纯色或极轻色阶。主体像高级玩具品牌艺术品、设计收藏品或现代编辑雕塑，清爽可爱但不幼稚。

自动文案从主体身份、动作、情绪、关系或有依据的含义中提炼一个简短标题，只在有用时增加零至两个标签词或微型注释。不得虚构品牌、套装编号、游戏关卡、产品线或技术规格。使用目标语言中自然的模块化、像素化或积木说明书式排版，与主体剪影、底座、积木缝、模块节奏或留白对齐。用户准确文案逐字保留。无文字模式保持同一积木、材质、配色和陈列逻辑，但不生成文字或伪文字。

## 模式与验收


硬性验收：至少三个源图线索；一个可识别积木主体；可信模块拼搭；清晰剪影与有依据的局部夸张；明艳源图色组与明显更浅背景；可信哑光 ABS、拼缝、厚度、接点和接触阴影；克制的目标语言模块文字；用户准确文案无改写；无复杂 Minecraft 世界、散砖、强行拟人、游戏 HUD、通用资产、低模网格、霓虹、粉彩、金属、玻璃、过度 CG、儿童界面、商品包装、样机或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
